# OmniAI – Intelligent Recommendation Agent

## Problem Statement

People often find it difficult to choose the best dress for an event because thousands of products are available across different shopping platforms. Users need to compare factors such as occasion, budget, style, brand, size, and platform before making a decision. This process can be time-consuming and confusing.

OmniAI solves this problem by acting as an intelligent recommendation agent. It understands the user's requirements, searches and analyzes available product options, compares them based on preferences and budget, and provides a small, ranked list of the most suitable choices.

## Objective

The objective of OmniAI is to make product selection faster, easier, and more personalized by automatically understanding user preferences and recommending the best options.

## How OmniAI Works

User Input
↓
Understand Requirements
↓
Search Product Options
↓
Filter by Budget and Preferences
↓
Compare Products
↓
Rank Best Options
↓
Display Top 5 Recommendations

## Example

User:
"I want a birthday party dress under ₹2,000 from Myntra or AJIO."

OmniAI considers:

- Occasion: Birthday Party
- Budget: ₹2,000
- Category: Dress
- Platforms: Myntra / AJIO
- Style Preference
- Brand Preference

The agent then provides the top 5 suitable recommendations with:

- Product name
- Brand
- Price
- Platform
- Rating
- Reason for recommendation

## Key Features
